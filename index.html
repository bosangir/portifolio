Research and software

My PhD develops statistical methods for integrating multi-omics data. Each method is released as open R software.

R package · simulation

SUMO

Simulation Utilities for Multi-Omics data. SUMO generates datasets with chosen latent factors, signal blocks, noise levels and heterogeneity. Because the true structure is known, methods for factor analysis, clustering and biclustering can be tested against it.

2025Bioinformatics Advances
Ropen source
SUMO on GitHub

Integrative clustering

M-ABC

Multi-data Aggregating Bundles of Clusters extends the ABC method to joint clustering of several data sources. It runs ensemble clustering within each dataset and combines the sample-level dissimilarities into one consensus structure.

Multi-sourceclustering

Factor-analysis methods for multi-omics

A systematic comparison of unsupervised factor-analysis methods for multi-omics integration, using known truth from SUMO and real radiobiology data.

Methods in development
